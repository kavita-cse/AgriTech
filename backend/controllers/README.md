# Backend Controllers
Business logic handlers will be implemented in subsequent phases per Architecture Version 2.3:
- `authController.js` (User registration, login, JWT issuance)
- `farmController.js` (Farm management & plot registry)
- `cropController.js` (Crop monitoring & phenology)
- `soilController.js` (Soil health evaluation with indicative rule engine)
- `marketController.js` (Marketplace products, carts, orders with single-vendor checkout rule)
- `forumController.js` (Community forum posts and comments)
- `expertController.js` (Consultation booking & expert workflows)
