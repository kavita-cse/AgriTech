# AgriTech – Empowering Farmers Through Digital Technology

AgriTech is a full-stack digital platform designed to empower agricultural communities by providing crop monitoring, indicative soil health analysis, localized weather forecasts and alerts, a single-seller resource marketplace, community forums, verified expert consultations, and administrative governance.

## Technology Stack
- **Frontend:** React.js, Bootstrap 5, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose ODM
- **Authentication & Security:** JWT (Bearer token), bcrypt password hashing, route-level authorization, and account active-status verification
